# Kara Kartal Stadium

A Claude Code theme inspired by a black-and-white football night. The app background becomes a floodlit stadium: two floodlight towers with slowly breathing beams, stands covered in black-and-white stripes, a crowd of softly twinkling lights, waving striped flags, a dark green pitch, and a pale eagle gliding across the sky. The app's colours switch to a dark, near-black-and-white palette with a cool floodlight-silver accent.

The theme draws in the Claude desktop and mobile apps. Terminals and editors don't draw themes. It uses no club crest, logo or font.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install kara-kartal-stadium --marketplace omer1903toker-stack/kara-kartal
```

Answer `y` to add the marketplace, then pick the user scope so the theme applies in every session.

From a shell:

```bash
claude plugin install kara-kartal-stadium --marketplace omer1903toker-stack/kara-kartal
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `omer1903toker-stack/kara-kartal`, then Add plugin.

If this repository is private, it installs only for people who can read it on GitHub and whose machine already has a git credential for github.com.
